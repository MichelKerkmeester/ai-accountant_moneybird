# cli-moneybird 1.0.0.0: Initial Release

The `cli-moneybird` skill guides the reconstruction of historical bookkeeping in Moneybird during a Jortt migration.

## Why This Release

This initial release adds a standalone skill that routes Moneybird REST work through the official CLI behind a local write guard. It leaves named UI-only tasks with the operator.

## NEW

- `SKILL.md` defines operation routing for REST reads, migration writes and UI-only steps.
- The official CLI is adopted at the reviewed commit. `moneybird-guard` adds dry-run inspection, a read-only lock, explicit write confirmation, a pilot gate, safe output paths and body-free write records.
- The package includes an offline CLI stub suite, a read-only local doctor and a setup script that installs only when passed `--install`.
- Four references cover CLI use, REST behavior, migration recipes and troubleshooting.
- A feature catalog lists every current feature with source files and validation anchors.
- The manual testing playbook covers setup, write safety, reads and routing boundaries. Each scenario links to its catalog entry. The live pilot rehearsal runs only with operator approval and writes only to the pilot administration.

## CHANGED

- Moneybird migration work has its own package beside the Moneybird Accountant system. Jortt source reads remain with the sibling `cli-jortt` skill.
- Verification guidance requires explicit periods, synchronization for bulk pulls and a pilot write with an undo rehearsal before production batches.

## NOT CHANGED

- No benchmark run has been recorded.
- No live Moneybird connection, OAuth grant or migration write is claimed by this release.
