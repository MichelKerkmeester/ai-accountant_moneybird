## 1. OVERVIEW

<a id="1-overview"></a>

Box 3 (savings and investments, sparen en beleggen) taxes a flat-rate return (forfaitair rendement) on assets and debts. For 2022 the old band method applies, with the base for savings and investments (grondslag sparen en beleggen) split over three bands that each mix return class I (rendementsklasse I, savings) and return class II (klasse ii) (rendementsklasse II, investments) (https://wetten.overheid.nl/BWBR0011353/2022-01-01). The Box 3 Restoration of Rights Act (Wet rechtsherstel box 3) is enacted and adds a second calculation for 2022 with the actual composition of the assets in three categories (https://zoek.officielebekendmakingen.nl/stb-2022-533.html). The Dutch Tax and Customs Administration (Belastingdienst) computes both methods and applies the more favourable one to the final assessment (definitieve aanslag) (https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/oude-berekening-box-3-inkomen). All 2022 values in this file are enacted and Verified.
