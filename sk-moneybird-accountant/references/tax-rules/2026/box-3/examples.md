## 2. WORKED EXAMPLES

<a id="4-worked-examples"></a>

### Official example: single with € 150.000 savings

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2026

- Banktegoeden € 150.000 x 1,28% = € 1.920.
- Rendementsgrondslag = € 150.000.
- Grondslag sparen en beleggen = € 150.000 - € 59.357 = € 90.643.
- Aandeel = € 90.643 / € 150.000 x 100 = 60,42% on the page. The exact figure is 60,4287%.
- Voordeel = € 1.920 x 60,42% = € 1.160.
- Tax = € 1.160 x 36% = € 417.

This is an `Official example`. The page prints these amounts.

### Official example: same savings with a partner

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2026

- Grondslag sparen en beleggen = € 150.000 - € 118.714 = € 31.286.
- The partners split it as € 15.643 each.
- Aandeel = € 15.643 / € 150.000 x 100 = 10,42% on the page.
- Voordeel = € 1.920 x 10,42% = € 200 each.
- Tax = € 200 x 36% = € 72 each.

This is an `Official example`. The page prints these amounts.

### Official example: single with savings, investments, a second home and debt

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2026

- Bank return = € 150.000 x 1,28% = € 1.920.
- Other assets = € 75.000 investments plus € 200.000 second home = € 275.000 x 6,00% = € 16.500.
- Aftrekbare schuld = € 100.000 - € 3.800 = € 96.200.
- Debt return = € 96.200 x 2,70% = € 2.597,40, printed as € 2.598.
- Belastbaar rendement = € 1.920 + € 16.500 - € 2.598 = € 15.822.
- Rendementsgrondslag = € 425.000 - € 96.200 = € 328.800.
- Grondslag = € 328.800 - € 59.357 = € 269.443.
- Aandeel = € 269.443 / € 328.800 x 100 = 81,94% on the page.
- Voordeel = € 15.822 x 81,94% = € 12.964.
- Tax = € 12.964 x 36% = € 4.667.

This is an `Official example`. The page prints these amounts.

### Calculated example: single with savings, investments and debt

Inputs are invented. Single person. Banktegoeden € 100.000, overige bezittingen € 50.000, schulden € 20.000.

- Bank return = € 100.000 x 1,28% = € 1.280.
- Other-assets return = € 50.000 x 6,00% = € 3.000.
- Debt above the drempel = € 20.000 - € 3.800 = € 16.200.
- Debt return = € 16.200 x 2,70% = € 437,40.
- Belastbaar rendement = € 1.280 + € 3.000 - € 437,40 = € 3.842,60.
- Rendementsgrondslag = € 150.000 - € 16.200 = € 133.800.
- Grondslag = € 133.800 - € 59.357 = € 74.443.
- Aandeel with the 3-decimal instruction = € 74.443 / € 133.800 x 100 = 55,6375%, rounded to 55,638%.
- Voordeel = € 3.842,60 x 55,638% = € 2.137,95.
- Tax = € 2.137,95 x 36% = € 769,66.

If the official example style is followed with truncation at 2 decimals, the aandeel is 55,63%, the voordeel is € 3.842,60 x 55,63% = € 2.137,64 and the tax is € 2.137,64 x 36% = € 769,55. This `Calculated example` shows the open rounding point.

### Calculated example: partners with savings and green investments

Inputs are invented. Whole-year partners. Banktegoeden € 150.000 and green investments € 100.000.

- Bank return = € 150.000 x 1,28% = € 1.920.
- Green exemption = € 53.430. Taxable green = € 100.000 - € 53.430 = € 46.570.
- Other-assets return = € 46.570 x 6,00% = € 2.794,20.
- Belastbaar rendement = € 1.920 + € 2.794,20 = € 4.714,20.
- Rendementsgrondslag = € 150.000 + € 100.000 - € 53.430 = € 196.570.
- Grondslag = € 196.570 - € 118.714 = € 77.856.
- Aandeel = € 77.856 / € 196.570 x 100 = 39,6073%, rounded to 39,607%.
- Voordeel = € 4.714,20 x 39,607% = € 1.867,15.
- Tax = € 1.867,15 x 36% = € 672,17.
- Korting groene beleggingen = 0,1% x € 53.430 = € 53,43.
- Tax after the korting = € 672,17 - € 53,43 = € 618,74.

This is a `Calculated example`.

### Calculated example: actual return lower than the fictitious return

Inputs are invented. Single person. Banktegoeden € 150.000 and overige bezittingen € 50.000 on 1 January 2026. No debts. During 2026 the bank pays € 500 interest and the investments fall by € 3.000.

Fictitious calculation:

- Bank return = € 150.000 x 1,28% = € 1.920.
- Other-assets return = € 50.000 x 6,00% = € 3.000.
- Belastbaar rendement = € 1.920 + € 3.000 = € 4.920.
- Rendementsgrondslag = € 200.000.
- Grondslag = € 200.000 - € 59.357 = € 140.643.
- Aandeel = € 140.643 / € 200.000 x 100 = 70,3215%, rounded to 70,322%.
- Voordeel = € 4.920 x 70,322% = € 3.459,84.
- Tax = € 3.459,84 x 36% = € 1.245,54.

Actual return:

- Interest € 500 plus value change negative € 3.000 = negative € 2.500.
- Art. 5.25 lid 2 sets the actual return at least nil. The actual return is € 0.
- The actual return is lower than the fictitious voordeel. Belastingdienst uses the most favourable amount, so the income becomes € 0 and the tax is € 0.

This is a `Calculated example`. It uses the content rules that no heffingsvrij vermogen is taken into account and that a negative total is set at nil.
