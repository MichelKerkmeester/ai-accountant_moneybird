## 2. WORKED EXAMPLES

<a id="4-worked-examples"></a>

The checked material contains no official example for 2021, so every example below is a `Calculated example` built from the section 2 figures. The inputs are invented round amounts.

### Calculated example 1. Single taxpayer, both methods, most favourable

Inputs on 1 January 2021: bank balances (banktegoeden) € 200.000, other assets (overige bezittingen) € 150.000, debts (schulden) € 20.000, no partner.

Band method, step by step:

1. Assets (bezittingen): € 200.000 + € 150.000 = € 350.000.
2. Deductible debts: € 20.000 - € 3.200 debt threshold (schuldendrempel) = € 16.800.
3. Return base (rendementsgrondslag): € 350.000 - € 16.800 = € 333.200.
4. Tax-free allowance (heffingsvrij vermogen) € 50.000, so the savings and investments base (grondslag sparen en beleggen) is € 333.200 - € 50.000 = € 283.200.
5. Band 1: € 50.000 x 1,898% = € 949,00.
6. Band 2: € 283.200 - € 50.000 = € 233.200, and € 233.200 x 4,501% = € 10.496,33.
7. Band 3: nothing, the base stays below € 950.000.
8. Benefit: € 949,00 + € 10.496,33 = € 11.445,33.
9. Tax: € 11.445,33 x 31% = € 3.548,05.

Category method (categorieënmethode) under the Box 3 Restoration of Rights Act (Wet rechtsherstel box 3), step by step:

1. Step 1 taxable return (belastbaar rendement): € 200.000 x 0,01% = € 20,00, plus € 150.000 x 5,69% = € 8.535,00, together € 8.555,00, minus € 16.800 x 2,46% = € 413,28, so € 8.141,72.
2. Step 2 return base: € 350.000 - € 16.800 = € 333.200.
3. Step 3 savings and investments base: € 333.200 - € 50.000 = € 283.200.
4. Step 4 share (aandeel): € 283.200 / € 333.200 x 100 = 84,9939976%. The checked sources do not state the 2021 rounding for this step, so the unrounded percentage is used here.
5. Step 5 benefit: € 8.141,72 x 84,9939976% = € 6.919,97.
6. Step 6 tax: € 6.919,97 x 31% = € 2.145,19.

Most favourable method (meest gunstige methode): € 2.145,19 from the category method is lower than € 3.548,05 from the band method, so the definitive assessment uses € 2.145,19.

### Calculated example 2. Whole-year partners, band method wins

Inputs on 1 January 2021: joint bank balances € 80.000, joint other assets € 90.000, joint debts € 10.400, whole-year partners.

Band method, step by step:

1. Assets: € 80.000 + € 90.000 = € 170.000.
2. Deductible debts: € 10.400 - € 6.400 threshold for whole-year partners = € 4.000.
3. Return base: € 170.000 - € 4.000 = € 166.000.
4. Tax-free allowance € 100.000 for partners, so the savings and investments base is € 166.000 - € 100.000 = € 66.000.
5. Band 1: € 50.000 x 1,898% = € 949,00.
6. Band 2: € 66.000 - € 50.000 = € 16.000, and € 16.000 x 4,501% = € 720,16.
7. Benefit: € 949,00 + € 720,16 = € 1.669,16.
8. Tax: € 1.669,16 x 31% = € 517,44.
9. The partners may divide the joint base in any ratio that totals 100%. With a 50/50 division each partner takes € 33.000 of the base, half of the benefit (€ 834,58) and half of the tax (€ 258,72).

Category method under the Box 3 Restoration of Rights Act, step by step:

1. Step 1 taxable return: € 80.000 x 0,01% = € 8,00, plus € 90.000 x 5,69% = € 5.121,00, together € 5.129,00, minus € 4.000 x 2,46% = € 98,40, so € 5.030,60.
2. Step 2 return base: € 166.000.
3. Step 3 savings and investments base: € 66.000.
4. Step 4 share: € 66.000 / € 166.000 x 100 = 39,7590361%.
5. Step 5 benefit: € 5.030,60 x 39,7590361% = € 2.000,12.
6. Step 6 tax: € 2.000,12 x 31% = € 620,04.

Most favourable method: € 517,44 from the band method is lower than € 620,04 from the category method, so the definitive assessment uses € 517,44.

### Calculated example 3. Green investments (groene beleggingen) with the exemption and the credit

Inputs on 1 January 2021: single person, green investments (groene beleggingen) € 70.000, bank balances € 150.000, no debts.

1. The green exemption is € 60.429 for a single person, so € 60.429 of the € 70.000 green investments is not counted.
2. Counted assets: € 150.000 + (€ 70.000 - € 60.429) = € 150.000 + € 9.571 = € 159.571.
3. No debts, so the return base is € 159.571 and the savings and investments base is € 159.571 - € 50.000 = € 109.571.
4. Band 1: € 50.000 x 1,898% = € 949,00.
5. Band 2: € 109.571 - € 50.000 = € 59.571, and € 59.571 x 4,501% = € 2.681,29.
6. Benefit: € 949,00 + € 2.681,29 = € 3.630,29.
7. Tax: € 3.630,29 x 31% = € 1.125,39.
8. Green investment credit (korting groene beleggingen): 0,7% x € 60.429 = € 423,00.
9. Tax after the credit: € 1.125,39 - € 423,00 = € 702,39.

The exemption is capped at the value of the green investments on 1 January, so a green balance below € 60.429 would exempt only that lower balance.

### Calculated example 4. Actual return (werkelijk rendement) with a loss

Inputs on 1 January 2021: single person, bank balances € 100.000, other assets € 50.000, no debts.

Fictitious calculation, band method:

1. Savings and investments base: € 150.000 - € 50.000 = € 100.000.
2. Band 1: € 50.000 x 1,898% = € 949,00.
3. Band 2: € 50.000 x 4,501% = € 2.250,50.
4. Benefit: € 949,00 + € 2.250,50 = € 3.199,50.
5. Tax: € 3.199,50 x 31% = € 991,85.

Fictitious calculation, category method:

1. Step 1 taxable return: € 100.000 x 0,01% = € 10,00, plus € 50.000 x 5,69% = € 2.845,00, so € 2.855,00.
2. Step 2 return base: € 150.000.
3. Step 3 savings and investments base: € 100.000.
4. Step 4 share: € 100.000 / € 150.000 x 100 = 66,6666667%.
5. Step 5 benefit: € 2.855,00 x 66,6666667% = € 1.903,33.
6. Step 6 tax: € 1.903,33 x 31% = € 590,03.

Actual return reported for the year: regular benefits (reguliere voordelen) € 500 plus value changes of minus € 2.400, total minus € 1.900. The actual return is at least nil, so the box 3 income becomes € 0, no tax-free allowance is applied in this calculation, and the negative € 1.900 cannot be carried to another year.

Outcome: the lowest fictitious amount is € 590,03 from the category method, the actual return gives € 0, and the Dutch Tax and Customs Administration (Belastingdienst) uses the most favourable amount. The box 3 income is € 0 and the tax is 31% x € 0 = € 0.
