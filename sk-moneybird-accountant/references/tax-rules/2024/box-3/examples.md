## 2. WORKED EXAMPLES

<a id="4-worked-examples"></a>

### Example 1: Single, savings only (Official example)

Inputs: bank balances (banktegoeden) € 150.000, no other assets, no debts, no partner.

Step 1: bank balances € 150.000 x 1,44% = € 2.160. Taxable return (belastbaar rendement) is € 2.160.
Step 2: return base (rendementsgrondslag) is € 150.000.
Step 3: tax base for savings and investments (grondslag sparen en beleggen) is € 150.000 - € 57.000 = € 93.000.
Step 4: share (aandeel) is € 93.000 / € 150.000 x 100 = 62,000%.
Step 5: benefit (voordeel) is € 2.160 x 62,000% = € 1.339.
Step 6: tax is 36% x € 1.339 = € 482.

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2024

### Example 2: Same with a fiscal partner (Official example)

Inputs: bank balances € 150.000, no other assets, no debts, fiscal partner for the whole year.

Step 1: bank balances € 150.000 x 1,44% = € 2.160.
Step 2: return base is € 150.000.
Step 3: tax base for savings and investments is € 150.000 - € 114.000 = € 36.000. The partners split it as € 18.000 each.
Step 4: share is € 18.000 / € 150.000 x 100 = 12,000%.
Step 5: benefit is € 2.160 x 12,000% = € 259 for each partner.
Step 6: tax is 36% x € 259 = € 93 for each partner.

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2024

### Example 3: Single, savings, investments, second home and debt (Official example)

Inputs: bank balances € 150.000, investments € 75.000, second home € 200.000, debt € 100.000, no partner.

Step 1:
- bank balances € 150.000 x 1,44% = € 2.160.
- other assets (overige bezittingen) € 75.000 + € 200.000 = € 275.000. Return € 275.000 x 6,04% = € 16.610.
- deductible debt (aftrekbare schuld) € 100.000 - € 3.700 = € 96.300. Return € 96.300 x 2,61% = € 2.513.
- taxable return € 2.160 + € 16.610 - € 2.513 = € 16.257.
Step 2: return base € 150.000 + € 275.000 - € 96.300 = € 328.700.
Step 3: tax base for savings and investments € 328.700 - € 57.000 = € 271.700.
Step 4: share € 271.700 / € 328.700 x 100 = 82,658%.
Step 5: benefit € 16.257 x 82,658% = € 13.437.
Step 6: tax 36% x € 13.437 = € 4.837.

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2024

### Example 4: Same with a fiscal partner (Official example)

Inputs: bank balances € 150.000, investments € 75.000, second home € 200.000, debt € 100.000, fiscal partner for the whole year.

Step 1:
- bank balances € 150.000 x 1,44% = € 2.160.
- other assets € 75.000 + € 200.000 = € 275.000. Return € 275.000 x 6,04% = € 16.610.
- debt threshold (schuldendrempel) € 7.400. Deductible debt € 100.000 - € 7.400 = € 92.600. Return € 92.600 x 2,61% = € 2.417.
- taxable return € 2.160 + € 16.610 - € 2.417 = € 16.353.
Step 2: return base € 150.000 + € 275.000 - € 92.600 = € 332.400.
Step 3: tax base for savings and investments € 332.400 - € 114.000 = € 218.400. The partners split it as € 109.200 each.
Step 4: share € 109.200 / € 332.400 x 100 = 32,851%.
Step 5: benefit € 16.353 x 32,851% = € 5.372 for each partner.
Step 6: tax 36% x € 5.372 = € 1.933 for each partner.

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2024

### Example 5: Partners with green investments (Official example)

Inputs: bank balances € 5.000, green investments € 150.000, second home abroad € 250.000, no debt, fiscal partners for the whole year.

Step 1:
- bank balances € 5.000 x 1,44% = € 72.
- green exemption € 142.502 with a whole-year partner. Taxable green investments € 150.000 - € 142.502 = € 7.498.
- other assets € 7.498 + € 250.000 = € 257.498. Return € 257.498 x 6,04% = € 15.552.
- taxable return € 72 + € 15.552 = € 15.624.
Step 2: return base € 5.000 + € 257.498 = € 262.498.
Step 3: tax base for savings and investments € 262.498 - € 114.000 = € 148.498, allocated to one partner.
Step 4: share € 148.498 / € 262.498 x 100 = 56,571%.
Step 5: benefit € 15.624 x 56,571% = € 8.838.
Step 6: tax 36% x € 8.838 = € 3.181.

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2024

### Example 6: Green investments credit (korting groene beleggingen) (Calculated example)

This example continues the inputs of example 5. The exempt green amount is € 142.502 because the partners hold € 150.000 of green investments and the whole-year partner exemption is € 142.502. The credit is 0,7% x € 142.502 = € 997,51. The Dutch Tax and Customs Administration (Belastingdienst) computes the credit automatically. For whole-year partners the credit is split in the same ratio as the green balance. This example uses only the 2024 figures from section 2.

Sources: https://wetten.overheid.nl/BWBR0011353/2024-01-01 https://www.belastingdienst.nl/wps/wcm/connect/bldcontentnl/belastingdienst/prive/inkomstenbelasting/heffingskortingen_boxen_tarieven/heffingskortingen/korting_voor_groene_beleggingen

### Example 7: Actual return lower than the fictitious benefit (Calculated example)

This example builds on example 1. The fictitious benefit is € 1.339 and the fictitious tax is € 482. Suppose the taxpayer makes plausible that the actual return is € 300. The box 3 income is then € 300 minus the personal deductions (persoonsgebonden aftrek). With no personal deductions, the tax is 36% x € 300 = € 108. The Dutch Tax and Customs Administration uses the most favourable amount, so the taxpayer pays € 108 instead of € 482. The actual return does not use the tax-free allowance (heffingsvrij vermogen).

Sources: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/wat-is-mijn-werkelijk-rendement https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/heffingsvrij-vermogen

### Example 8: Negative actual return set at nil (Calculated example)

Suppose the actual return has € 200 of interest and a value loss of € 500. The net actual return is € 200 - € 500 = minus € 300. A negative total is set at € 0 and cannot be carried to another year. The box 3 income on the actual-return route is € 0.

Sources: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/wat-is-mijn-werkelijk-rendement
