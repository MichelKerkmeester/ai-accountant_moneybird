## 2. WORKED EXAMPLES

<a id="4-worked-examples"></a>

The checked material lists no official example for 2027 ("None found"), so every example below is a **Calculated example**. Each example uses the figures printed in the 2027 text from section 2. The bank percentage (1,37%), the debt percentage (2,70%) and the other-assets percentage (6%) are not final for 2027, and the tax-free allowance (heffingsvrij vermogen, € 59.357) and the debt threshold (schuldendrempel, € 3.800 and € 7.600) are still before the December 2026 indexation. The outcomes show the method, not a final 2027 assessment. No example applies the proposed indexation factor 1,01248 or the proposed plus 1,5 percentage point, because the checked sources do not state the resulting figures. Example 7 shows the effect of the proposed tax-free allowance of € 30.846, which is a stated amount.

**Example 1. Calculated example. Single taxpayer, bank balances (banktegoeden) € 150.000 on 1 January 2027, no other assets, no debts.**

- Step 1: taxable return (belastbaar rendement) = € 150.000 x 1,37% = € 2.055,00.
- Step 2: debts minus threshold = € 0, so return base (rendementsgrondslag) = € 150.000 - € 0 = € 150.000.
- Step 3: taxable base for savings and investments (grondslag sparen en beleggen) = € 150.000 - € 59.357 = € 90.643.
- Step 4: share (aandeel) = € 90.643 / € 150.000 x 100 = 60,428666%, rounded to three decimals 60,429%. The 2027 rounding instruction is not in the checked sources, so this example uses the three-decimal instruction printed for 2024 and 2026.
- Step 5: benefit (voordeel) = € 2.055,00 x 60,429% = € 1.241,82.
- Step 6: tax = 36% x € 1.241,82 = € 447,06.

**Example 2. Calculated example. Single taxpayer with bank balances € 150.000, investments (beleggingen) € 75.000, a second home of € 200.000 and a debt of € 100.000 on 1 January 2027.**

- Other assets (overige bezittingen) = € 75.000 + € 200.000 = € 275.000.
- Step 1: bank return = € 150.000 x 1,37% = € 2.055,00. Other-assets return = € 275.000 x 6,00% = € 16.500,00. Debts minus threshold = € 100.000 - € 3.800 = € 96.200. Debt return = € 96.200 x 2,70% = € 2.597,40. Taxable return = € 2.055,00 + € 16.500,00 - € 2.597,40 = € 15.957,60.
- Step 2: return base = € 150.000 + € 275.000 - € 96.200 = € 328.800.
- Step 3: taxable base = € 328.800 - € 59.357 = € 269.443.
- Step 4: share = € 269.443 / € 328.800 x 100 = 81,947384%, rounded 81,947%.
- Step 5: benefit = € 15.957,60 x 81,947% = € 13.076,77.
- Step 6: tax = 36% x € 13.076,77 = € 4.707,64.

**Example 3. Calculated example. The same assets as example 2, with a whole-year fiscal partner, taxable base split 50/50.**

- The threshold doubles to € 7.600. Debts minus threshold = € 100.000 - € 7.600 = € 92.400.
- Step 1: bank return € 2.055,00 + other-assets return € 16.500,00 - debt return (€ 92.400 x 2,70% = € 2.494,80) = € 16.060,20.
- Step 2: return base = € 150.000 + € 275.000 - € 92.400 = € 332.600.
- Step 3: the tax-free allowance doubles, € 59.357 x 2 = € 118.714. Joint taxable base = € 332.600 - € 118.714 = € 213.886. Half each = € 213.886 / 2 = € 106.943.
- Step 4: personal share = € 106.943 / € 332.600 x 100 = 32,153638%, rounded 32,154%. The personal share is calculated using the joint return base, as in the 2026 official partner example.
- Step 5: benefit per partner = € 16.060,20 x 32,154% = € 5.164,00.
- Step 6: tax per partner = 36% x € 5.164,00 = € 1.859,04.
- The partners may divide the joint taxable base in any ratio that totals 100%, so the 50/50 split here is one choice.

**Example 4. Calculated example. Whole-year partners with bank balances € 5.000, green investments € 150.000 and a second home abroad of € 250.000 on 1 January 2027, no debts. The whole taxable base goes to one partner.**

- Green exemption: € 400 for the couple. Under art. 5.13 lid 2 it applies first to green other assets, so the taxable green investments are € 150.000 - € 400 = € 149.600.
- Step 1: bank return = € 5.000 x 1,37% = € 68,50. Other assets = € 149.600 + € 250.000 = € 399.600. Other-assets return = € 399.600 x 6,00% = € 23.976,00. Taxable return = € 68,50 + € 23.976,00 = € 24.044,50.
- Step 2: assets = € 5.000 + € 150.000 + € 250.000 = € 405.000. The exempt € 400 is not an asset. Return base = € 405.000 - € 400 = € 404.600.
- Step 3: tax-free allowance = € 59.357 x 2 = € 118.714. Taxable base = € 404.600 - € 118.714 = € 285.886, allocated to one partner.
- Step 4: share = € 285.886 / € 404.600 x 100 = 70,658922%, rounded 70,659%.
- Step 5: benefit = € 24.044,50 x 70,659% = € 16.989,60.
- Step 6: tax = 36% x € 16.989,60 = € 6.116,26.
- Green investment credit (korting groene beleggingen): 0,1% x € 400 = € 0,40 for the couple, computed automatically and split in the same ratio as the green balance. If the green investments are held 50/50, each partner gets € 0,20.

**Example 5. Calculated example. Single taxpayer, bank balances € 50.000 on 1 January 2027, no other assets, no debts.**

- Step 1: taxable return = € 50.000 x 1,37% = € 685,00.
- Step 2: return base = € 50.000 - € 0 = € 50.000.
- Step 3: taxable base = € 50.000 - € 59.357 = negative. There is no taxable base to tax, and the flat-rate benefit (forfaitaire voordeel) cannot be negative (art. 4.14 lid 1, Stb. 2022, 534).
- Step 5: benefit = € 0. Step 6: tax = € 0.

**Example 6. Calculated example. The actual return against the fictitious benefit, single taxpayer with the assets of example 1.**

- The fictitious benefit from example 1 is € 1.241,82 and the fictitious tax is € 447,06.
- Case A: the actual return over the calendar year 2027 is € 600 and the taxpayer makes this plausible. € 600 is lower than € 1.241,82, so the income becomes € 600 minus any personal deductions (persoonsgebonden aftrek). With no personal deductions, the benefit is € 600 and the tax is 36% x € 600 = € 216,00.
- Case B: the actual return is a loss of € 1.000. The actual return is set at least at nil (art. 5.25 lid 2), so the benefit is € 0 and the tax is € 0.
- The actual return route uses no tax-free allowance. Reporting is optional, the Dutch Tax and Customs Administration (Belastingdienst) applies the most favourable amount, and you never pay more than the fictitious calculation of € 447,06 for this asset position.

**Example 7. Calculated example, based on a proposed figure. The Cabinet letter proposal of € 30.846 against example 1.**

- The return base stays € 150.000 and the taxable return stays € 2.055,00.
- Taxable base under the proposal = € 150.000 - € 30.846 = € 119.154.
- Share = € 119.154 / € 150.000 x 100 = 79,436%.
- Benefit = € 2.055,00 x 79,436% = € 1.632,41.
- Tax = 36% x € 1.632,41 = € 587,67.
- Against € 447,06 in example 1 that is € 140,61 more tax. The € 30.846 is proposed in the Cabinet letter of 29 September 2026 and is not in a published bill text, so this outcome has no legal effect on 2026-10-11.
