## 2. WORKED EXAMPLES

<a id="4-worked-examples"></a>

Every example below uses only the 2023 figures from section 2. Mark each example either `Official example` (copied from a primary source, linked) or `Calculated example` (built here from the section 2 figures).

### Example 1: single person with € 150.000 savings (Official example)

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2023

Step 1, taxable return (belastbaar rendement): € 150.000 x 0,92% = € 1.380.
Step 2, return base (rendementsgrondslag): € 150.000, no debts.
Step 3, base (grondslag): € 150.000 - € 57.000 = € 93.000.
Step 4, share (aandeel): € 93.000 / € 150.000 x 100 = 62,00%.
Step 5, benefit (voordeel): € 1.380 x 62,00% = € 855.
Step 6, tax: 32% x € 855 = € 273.

### Example 2: partners with € 350.000 savings (Official example)

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2023

Step 1: € 350.000 x 0,92% = € 3.220.
Step 2: return base € 350.000.
Step 3: € 350.000 - € 114.000 = € 236.000, split € 118.000 each.
Step 4: € 236.000 / € 350.000 x 100 = 67,4286%, printed rounded as 33,71% per partner (one half of 67,43%).
Step 5: € 3.220 x 33,71% = € 1.085 each.
Step 6: 32% x € 1.085 = € 347 each.

### Example 3: partners with savings, investments and a debt (Official example)

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/berekening-box-3-inkomen-2023

Inputs: € 100.000 savings, € 150.000 investments, € 50.000 debt.
Step 1a, asset return: € 100.000 x 0,92% = € 920, plus € 150.000 x 6,17% = € 9.255. Total € 10.175.
Step 1b, deductible debt (aftrekbare schuld): € 50.000 - € 6.800 = € 43.200. Debt return: € 43.200 x 2,46% = € 1.063 (rounded).
Step 1c, taxable return: € 10.175 - € 1.063 = € 9.112.
Step 2, return base: € 100.000 + € 150.000 - € 43.200 = € 206.800.
Step 3, base: € 206.800 - € 114.000 = € 92.800, all to one partner.
Step 4, share: € 92.800 / € 206.800 x 100 = 44,87%.
Step 5, benefit: € 9.112 x 44,87% = € 4.088 (rounded).
Step 6, tax: 32% x € 4.088 = € 1.308 (rounded).

### Example 4: negative actual return (werkelijk rendement) set at nil (Official example)

Source: https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/wat-is-mijn-werkelijk-rendement

Actual return (werkelijk rendement) 2023: € 800 interest and crypto down € 1.200 give minus € 400, set at € 0. The loss cannot be carried to another year.

### Example 5: invented single taxpayer (Calculated example)

Inputs: bank balances (banktegoeden) € 80.000, other assets (overige bezittingen) € 20.000, debts (schulden) € 10.000.
Step 1a, asset return: € 80.000 x 0,92% = € 736. € 20.000 x 6,17% = € 1.234. Sum € 1.970.
Step 1b, deductible debt: € 10.000 - € 3.400 = € 6.600. Debt return: € 6.600 x 2,46% = € 162,36.
Step 1c, taxable return: € 1.970 - € 162,36 = € 1.807,64.
Step 2, return base: € 100.000 - € 6.600 = € 93.400.
Step 3, base: € 93.400 - € 57.000 = € 36.400.
Step 4, share: € 36.400 / € 93.400 x 100 = 38,9722%, rounded to 2 decimals = 38,97%.
Step 5, benefit: € 1.807,64 x 38,97% = € 704,44 (rounded).
Step 6, tax: 32% x € 704,44 = € 225,42.
Check: the benefit is positive, so art. 4.14 lid 1 does not set it at nil.

### Example 6: invented figures that give a nil benefit (Calculated example)

Inputs: bank balances € 60.000, other assets € 10.000, debts € 25.000.
Step 1a, asset return: € 60.000 x 0,92% = € 552. € 10.000 x 6,17% = € 617. Sum € 1.169.
Step 1b, deductible debt: € 25.000 - € 3.400 = € 21.600. Debt return: € 21.600 x 2,46% = € 531,36.
Step 1c, taxable return: € 1.169 - € 531,36 = € 637,64.
Step 2, return base: € 70.000 - € 21.600 = € 48.400.
Step 3, base: € 48.400 - € 57.000 = negative, so nil.
Because the base is nil, the share is nil and the benefit is nil, and the box 3 tax is nil for this person. This is the effect of the tax-free allowance (heffingsvrij vermogen) of € 57.000. https://www.belastingdienst.nl/wps/wcm/connect/nl/box-3/content/heffingsvrij-vermogen

### Example 7: green investments (groene beleggingen) and the exemption order rule (Calculated example)

Inputs: a single taxpayer holds € 40.000 green bank balances and € 40.000 green other assets on 1 January 2023. The 2023 exemption for a single person is € 65.072. Art. 5.13 lid 2 applies the exemption first to the green other assets and only the remaining room to the green bank balances. So € 40.000 of the exemption goes to the green other assets, leaving € 25.072 of room for the green bank balances. The exemption never exceeds the value of the green investments on 1 January, and here € 65.072 is less than the total of € 80.000, so the full exemption room is used. The green investment credit (korting voor groene beleggingen) is 0,7% of the exempt amount on the reference date (peildatum), so 0,7% x € 65.072 = € 455,50, computed automatically. https://wetten.overheid.nl/BWBR0011353/2023-01-01 https://www.belastingdienst.nl/wps/wcm/connect/bldcontentnl/belastingdienst/prive/vermogen_en_aanmerkelijk_belang/vermogen/beleggen_met_belastingvoordeel/groene_beleggingen
