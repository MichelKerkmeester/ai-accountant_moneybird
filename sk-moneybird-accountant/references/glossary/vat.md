# Glossary of VAT terms

**Rule:** Every reference leads with the English term and adds the Dutch term in brackets at its first use in a section, for example "supplementary assessment (naheffingsaanslag)". [The glossary router](README.md) says which file holds which terms.

---

## 1. OVERVIEW

Value added tax (btw) terms: rates, the return boxes, reverse charge, the small businesses scheme and EU trade. A note of `plain` marks an everyday word or phrase whose Dutch adds nothing, so it needs no label. A note of `official name` marks the name of an authority, a law, a scheme, a form or a product, labelled once per file. A note of `abbreviation` marks a Dutch short form that English text keeps as it is after the full English name. An empty note marks a term that takes its label at its first use in each H2 section.
