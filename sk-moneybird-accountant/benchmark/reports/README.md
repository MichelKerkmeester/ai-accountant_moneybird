## 3. STORAGE RULE

Run folders are named `<YYYY-MM-DD>--<subject>--<variant>`, dated by execution. Keep the run summaries and machine-readable result tables here and raw transcripts and copied artifacts in the source packet named by the report. For a re-run that confirms the same headline, update the existing report with a `Re-run YYYY-MM-DD` line instead of creating a folder.

The grammar and the report file set are owned by `create-benchmark`. This index states them only so the folder reads on its own, and that skill is correct where the two differ.
