## 3. STORAGE RULE

Run folders use the date of execution, a subject, and a variant. Keep curated summaries and machine-readable result tables here. Keep raw transcripts and copied artifacts in the source material named by the report. A changed result gets a new folder rather than overwriting a prior one.

The grammar and the report file set are owned by `create-benchmark`. This index states them only so the folder reads on its own. Where the two differ, that skill is correct.
